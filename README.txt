云养小猫 V4.5 模块化版｜成就与称号

上传方式：将本文件夹中的 index.html、style.css、cats.js、encyclopedia.js、relationships.js、events.js、tasks.js、achievements.js、assets.js、game.js、sw.js 全部上传到 GitHub 仓库根目录。保留现有 assets 文件夹。

文件职责：
index.html          页面结构
style.css           横屏界面、手机适配、动画、图鉴与成就样式
game.js             游戏状态、存档、猫舍、背包、成就界面和主流程
cats.js             猫咪品种、性格与获得方式
encyclopedia.js     猫咪图鉴资料、发现记录和完成度
relationships.js    亲密等级、解锁、专属反应与迎接事件
events.js           普通互动事件和每日随机选择事件
tasks.js            每日任务
achievements.js     成就条件、累计进度、解锁事件与称号佩戴
assets.js           WebP资源清单
sw.js               网站文件与WebP本地缓存

V4.5 新增：
1. 新增24项长期成就，分为养成旅程、日常照顾、关系羁绊、收集探索、长期挑战五类。
2. 成就会记录喂食、摸猫、陪玩、清洁、护理、购物、每日任务和随机事件等累计进度。
3. 每项成就都会解锁一个称号，可在成就页面自由佩戴或隐藏。
4. 当前称号会显示在主房间的猫咪信息旁。
5. 成就页面支持全部、已完成、进行中筛选，并显示完成度和实时进度。
6. 解锁成就时会出现专属弹窗，并自动写入当前猫咪日记。
7. 包含猫咪图鉴、三种性格、美短银虎斑、形影不离、幸福猫舍、灾后重建等特殊成就。
8. 旧存档会自动迁移到存档版本10；能从现有数据判断的成就会自动补齐，不会连续弹出大量旧成就。
9. Service Worker与本地图片缓存版本已更新。

注意：必须同时上传全部代码文件，尤其是新增的 achievements.js。第一次打开新版时建议在网址末尾增加 ?v=28，或关闭旧标签后重新进入。
