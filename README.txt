云养小猫 V4.2 模块化版

上传方式：将本文件夹中的 index.html、style.css、cats.js、events.js、tasks.js、assets.js、game.js、sw.js 全部上传到 GitHub 仓库根目录。保留现有 assets 文件夹。

文件职责：
index.html  页面结构
style.css  横屏界面与动画
game.js    游戏状态、存档、界面和主流程
cats.js    猫咪品种、性格与获得方式
events.js  普通互动事件和每日随机选择事件
tasks.js   每日任务
assets.js  WebP 资源清单
sw.js      网站与图片本地缓存

注意：必须同时上传全部代码文件，不能只替换 index.html。
