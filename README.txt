云养小猫 V4.3.1 模块化版｜每日随机事件扩充

上传方式：将本文件夹中的 index.html、style.css、cats.js、relationships.js、events.js、tasks.js、assets.js、game.js、sw.js 全部上传到 GitHub 仓库根目录。保留现有 assets 文件夹。

文件职责：
index.html          页面结构
style.css           横屏界面、手机适配与动画
game.js             游戏状态、存档、猫舍、背包和主流程
cats.js             猫咪品种、性格与获得方式
relationships.js    亲密等级、解锁、专属反应与迎接事件
events.js           普通互动事件和每日随机选择事件
tasks.js            每日任务
assets.js           WebP 资源清单
sw.js               网站文件与 WebP 本地缓存

V4.3.1 新增：
1. 灵珠新增10个专属每日随机选择事件。
2. 魔丸新增10个专属每日随机选择事件。
3. 耄耋新增10个专属每日随机选择事件。
4. 每个事件都有3个处理选项，并会根据金币、行动次数、背包库存、饱腹、健康和房屋状态启用或禁用选项。
5. 新事件会影响饱腹、健康、清洁、亲密、信任、活力、胆量、金币和房屋损坏。
6. 原有随机事件、猫舍、背包、任务和亲密等级系统全部保留。
7. 缓存版本已更新，确保 events.js 能及时替换旧版本。

新增事件示例：
灵珠：温柔的晨间叫醒、陪你写作业、失踪的发圈、雨天窗台、瓶盖礼物、陌生客人来访、水碗倒影、刚晒好的衣服、撒娇提醒吃饭、床边守夜。
魔丸：纸巾雪、占领键盘、沙发底私房钱、鞋带伏击、花盆考古、凌晨演唱会、研究门把手、猫粮袋劫案、洗衣篮伏击、镜中对手。
耄耋：守护食盆、追击影子、高处据点、撕开的旧玩具、航空箱堡垒、罕见停战、抓挠门板、雷雨藏身、玻璃倒影、护理用品对峙。

注意：必须同时上传全部代码文件，不能只替换 index.html。第一次打开新版时建议在网址末尾增加 ?v=26，或关闭旧标签后重新进入，以确保 Service Worker 更新。
